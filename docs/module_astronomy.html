Usage

dynamics::State<T> s = prop.propagate(math::exact<T>(minutes));

// Absolute epoch of this sample (two-part; day part preserved).
TV jd = el.epoch_jd + math::exact<T>(minutes) / math::exact<T>(1440);
TV t_tt = astronomy::centuries_since_j2000<T>(jd);

// TEME -> GCRS by the inverse precession (dominant term; note above).
math::Vector3<T> r_teme = s.position();
math::Vector3<T> r_gcrs = astronomy::precession_iau2006<T>(t_tt).transpose() * r_teme;

// GCRS -> ITRS: nutation + GAST + polar motion (x_p = y_p = 0 demo EOP).
math::Matrix3<T> M = astronomy::gcrs_to_itrs<T>(
    t_tt, jd, math::exact<T>(0), math::exact<T>(0));
math::Vector3<T> r_itrs = M * r_gcrs;

functionastronomy::sidereal_rotation
template<typename T>
math::Matrix3<T> sidereal_rotation(const math::TrackedValue<T>& gmst)
TEME→ECEF (PEF) sidereal rotation R = Rz(GMST), the SGP4 convention (no equation of equinoxes, no polar motion). The inverse (ECEF→TEME) is its transpose. Applied to a position vector this is BIT-IDENTICAL to the prior hand-coded componentwise rotation in forces/gravity_tesseral.h (the +0·z terms are exact no-ops, 1·z and a+(-b) are IEEE-exact), so the migration is value-preserving.

@file nutation_terms_iau2000a.h
IAU 2000A LUNI-SOLAR nutation series -- AUTO-GENERATED by
tools/gen_nutation_terms.py from the in-repo born-digital SOFA table
(sgp4_references/vallado_celestrak/datalib/iau00ansofa.dat). Do not edit;
re-run the generator. 678 terms, SORTED by amplitude so a truncated
n_terms evaluation keeps the largest terms (the dial-up pattern).
Coefficients are EXACT INTEGERS in 1e-7 arcsec (the SOFA unit):
dpsi = sum (psi_sin + psi_t_sin*t) sin(th) + psi_cos cos(th)
deps = sum (eps_cos + eps_t_cos*t) cos(th) + eps_sin sin(th)
th = l*L + lp*L' + f*F + d*D + om*Om (the Delaunay arguments).
The PLANETARY series (687 terms, iau00anplsofa.dat) is NOT modeled;
its total |amplitude| is the omitted-model accuracy floor below.
Theory: design/derivations/nutation_itrs.md.
