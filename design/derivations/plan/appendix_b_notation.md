# Draft Plan: Appendix B — Notation and Symbol Index

## Objectives

1. Provide a complete alphabetical listing of every symbol used in the textbook.
2. Give for each symbol: its meaning, the section where it is formally defined, and which chapters use it.
3. Distinguish between symbols used in multiple contexts (e.g., $e$ = eccentricity in orbital mechanics vs. $e$ = first eccentricity of the ellipsoid) by explicit namespace labeling.

## Section Structure

### §B.1 Greek Symbols

This section provides an alphabetical table of all Greek symbols used in the textbook with formal definition locations and chapter usage.

Stub: Alphabetical table. Columns: symbol (LaTeX), name, meaning, definition location, chapters used. Entries include: $\alpha, \beta$ (commensurability integers; Ch 28), $\delta_a$ (accuracy error; Ch 1), $\delta_p$ (precision error; Ch 1), $\epsilon$ (dual number unit; Ch 2), $\eta = \sqrt{1-e^2}$ (eccentricity factor; Ch 16), $\theta_{\mathrm{GMST}}$ (Ch 29), $\lambda$ (resonant phase angle; Ch 28; also longitude in Ch 28.5), $\mu = GM$ (gravitational parameter; Ch 8), $\sigma_m$ (measurement error; Ch 1), $\tau$ (tolerance; Ch 3; also density power-law exponent in Ch 21 — explicit disambiguation), $\omega$ (argument of perigee; Ch 8), $\omega_E$ (Earth rotation rate; Ch 29), etc.

### §B.2 Roman Symbols

This section provides an alphabetical table of all Roman symbols with the same format as §B.1.

Stub: Alphabetical table, same format. Entries include all elements ($a, e, i, \Omega, \omega, M$), all Kaula functions ($F_{lmp}, G_{lpq}$), Brouwer elements, dual quaternion symbols ($\hat{M}, \hat{\Omega}$), error tracking symbols ($\mathcal{V}$, tracked value), etc.

### §B.3 Special Notation

This section explains the typographic conventions used uniformly throughout the textbook: basis subscripts, dual operators, element primes, and epoch subscripts.

Stub: Conventions explained: basis subscript $_b$ on all frame-specific vectors (rule: every vector quantity carries a subscript indicating its frame of expression); the dual extension operator $\varepsilon$; the operator overhat $\hat{\cdot}$ denoting dual quaternion; the prime $(\cdot)'$ for osculating elements; the double-prime $(\cdot)''$ for recovered mean elements; the subscript $_o$ for epoch values.

### §B.4 Disambiguation Table

This section explicitly lists every overloaded symbol with its distinct meanings, the chapters where each meaning applies, and the disambiguation convention.

Stub: Explicit list of symbols with context-dependent meanings. For each overloaded symbol: the distinct meanings, their chapters, and the convention for disambiguation. Examples: $e$ (eccentricity vs. ellipsoid eccentricity), $\tau$ (tolerance vs. density exponent), $n$ (mean motion vs. harmonic degree), $p$ (semi-latus rectum vs. harmonic order in Kaula).
